# Jeu du Pendu — Test manuel (JavaScript / HTML / CSS)

Petit jeu du pendu en JavaScript/HTML/CSS réalisé pendant ma formation Testeur QA (Bruxelles Formation / Cefora), accompagné d'un **rapport de test manuel complet** que j'ai rédigé sur ma propre logique de jeu.

Le rapport (`rapport-de-test-pendu.md`) couvre 15 cas de test structurés selon une vraie démarche QA : tests aux limites, classes d'équivalence, tests de non-régression, avec un journal d'anomalies détecté (bugs mineurs identifiés et documentés).

Objectif : démontrer une application concrète des techniques de test manuel vues en formation (stratégie de test, cas de test, anomalies) sur un projet que j'ai développé moi-même.
