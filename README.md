# Hangman — Manual Testing (JavaScript / HTML / CSS)

A small hangman game in JavaScript/HTML/CSS built during my QA Tester training (Bruxelles Formation / Cefora), together with a **complete manual test report** that I wrote for my own game logic.

The report (`rapport-de-test-pendu.md`, written in French) covers 15 structured test cases following a real QA approach: boundary testing, equivalence classes and regression testing, with a defect log (minor bugs identified and documented).

Goal: demonstrate a concrete application of the manual testing techniques learned during the training (test strategy, test cases, defects) on a project I developed myself.
